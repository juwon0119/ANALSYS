[도면 대응 위치 비교 화면 개선]

1. 프로그램에서 기준 PDF와 검토 DXF를 선택합니다.
2. 02 분석 및 수정 제안에서 차이 항목을 선택하고
   [선택 항목 차이 검토 · 도면 표시] 버튼을 누릅니다.
3. 비교 결과창 상단에서 기준 PDF(왼쪽), 검토 DXF(오른쪽)를
   나란히 확인합니다.
4. 항목별 표시 기준:
   - 중심선 누락 후보: 파란 타원
   - 지름·치수 차이: 빨간 사각형
   - 형상 차이 후보: 파란 사각형
   - 공차 누락·차이: 초록 사각형
   - 텍스트 차이: 주황 사각형
5. 같은 번호의 도형은 동일한 검토 항목을 의미합니다.
   목록에서 해당 항목 선택 시 굵은 실선으로 강조됩니다.
6. 좌표를 신뢰할 수 없는 차이는 임의 표시하지 않습니다.
   [PDF 위치 지정]/[DXF 위치 지정]으로 원본 도면에
   마우스 오른쪽 버튼을 드래그해 영역을 지정합니다.
7. [비교 이미지 PNG 저장]으로 나란히 배치된 검토 화면을 저장합니다.

[정확도에 관한 안내]
- PDF 텍스트와 DXF 치수 표기가 일대일 대응할 때만 자동 수치 차이를 판정합니다.
- 중심선과 자유곡면 형상 차이는 자동으로 확정하지 않으며,
  확인 근거가 없으면 '확인 필요'로 남습니다.
- 표시 색상은 검토용 오버레이이며 원본 PDF/DXF를 수정하지 않습니다.
- 기존 DXF 수정 승인은 별도 절차이며, 자동 수정 범위는 기존과 같습니다.
