수정본 3D 형상 표시 안내
======================

1. 우측 상단: 기준 PDF / 원본 STP
2. 우측 중간: 검토 DXF / 검토 STP
3. 우측 하단: 검토용 PDF / 수정본 STP

우측 하단의 ‘수정 STP 선택’을 눌러 CATIA에서 별도로 수정 후 내보낸 STEP/STP 파일을 선택하세요.
실습 번호별로 선택한 수정본 형상의 절대 경로가 사용자 설정 document_info.json에 저장됩니다.
다음에 같은 실습을 선택하면 파일이 실제로 존재하는 경우 자동으로 다시 불러옵니다.
실습 폴더에 <실습번호>_A00_corrected.stp 또는 .step 파일이 있으면 자동으로 검색합니다.

중요: 현재 '수정안 승인 및 DXF 저장'은 2D DXF 내의 깊이 표기 수정 기능입니다.
DXF 문자 수정으로는 CATIA의 3D 형상이 실제로 변경되지 않습니다.
따라서 별도 수정본 STP가 없으면 프로그램은 3D 수정 결과를 만들어냈다고 표시하지 않습니다.

STP는 원본에 지정된 색상, 음영, 검은 윤곽선을 이용하여 표시합니다.
