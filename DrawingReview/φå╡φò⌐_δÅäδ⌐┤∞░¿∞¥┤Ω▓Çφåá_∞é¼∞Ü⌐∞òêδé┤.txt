도면 검토 통합 실습 - 형상/치수/중심선/공차/텍스트 차이 검토
=============================================================

[프로그램 실행]
1. 처음 설치한 PC: Setup.cmd 실행 (Windows / 64-bit Python 필요)
2. Run.cmd 실행
3. 01 도면 선택에서 기준 PDF와 검토 DXF 선택
4. 02 분석 및 수정 제안 -> 아래의 통합 검토 항목을 체크
5. [선택 항목 차이 검토 · 도면 표시] 클릭
6. 도면 차이 결과 목록에서 항목을 선택하면 PDF/DXF의 해당 표기 위치를 표시함

[색상 범례]
- 중심선: 파란 타원 (위치를 찾지 못한 항목은 수동 지정)
- 지름/치수: 빨간 사각형
- 형상: 파란 사각형
- 공차: 녹색 사각형
- 텍스트: 주황색 사각형

[비교 결과 판정 원칙]
- '불일치': 동일한 문맥의 치수 표기를 하나로 매칭하여 값이 다름을 확인한 경우
- '확인 필요': 배치, 치수 연결, PDF 표기 추출 또는 도면 투영 관계가 부족한 경우
- 표기가 일치해도 실제 가공 형상·부품 공차 적합이 증명되는 것은 아님
- PDF와 DXF의 선종류 저장 방식이 다르면 중심선 자동 대조는 확정할 수 없음
- PDF가 스캔 이미지일 경우 텍스트 추출이 불가능하거나 불완전할 수 있음
- 일반 치수/형상/위치가 다른지 판단하려면 기준점과 동일 뷰를 식별해야 함

[도면 위 표시 및 검토자 학습]
1. 검토 결과의 해당 항목을 클릭하여 자동 매칭된 표기 위치를 확인
2. 자동 표시가 없거나 위치가 불명확할 때 [PDF 위치 지정] 또는 [DXF 위치 지정]
3. 원하는 도면 위에서 마우스 오른쪽 버튼으로 드래그하면 지정한 영역에 표시
4. [검토 판단 저장]에서 오류 확정/추가 확인/정상 또는 허용을 선택하고 사유 작성
5. [학습 사례 보기]로 이전 판단 절차와 기록 검토
6. 결과는 [텍스트 보고서]로 내보내거나 좌측의 [검토 결과 저장]으로 저장

[자동 수정과의 관계]
- 이 기능은 비파괴 차이 검토/표시/학습 기능이며 모든 CAD 치수를 자동 수정하지 않음
- 기존 [깊이 표기 검토]와 [수정안 승인 및 DXF 저장]은 종전대로 작동
- 기존 수정안 저장은 검토 DXF의 해당 깊이 표기에 한정됨
- 우측 하단 수정본 DXF 미리보기는 승인·저장에 성공하기 전까지 빈 화면을 유지
- 우측 하단 예약된 3D 기능 칸은 계속 비워 두며 새로운 형상 뷰어를 만들지 않음
- 판단 이력은 difference_decisions.sqlite3에 저장. 이전 사례의 치수값을 자동 적용하지 않음

[제한 사항]
본 확장판은 모든 CAD 객체와 PDF 벡터 도형 사이의 자동 기하학적 대응을
완전하게 해결하지 않음. 중심선 누락, 형상 투영 차이, 일부 공차는
추가 확인 후보이며 검토자가 도면의 대상 위치를 지정하고 확인할 수 있음.
전 부품 형상 자동 판정이나 3D STP 솔리드 자동 변경 기능은 포함하지 않음.
