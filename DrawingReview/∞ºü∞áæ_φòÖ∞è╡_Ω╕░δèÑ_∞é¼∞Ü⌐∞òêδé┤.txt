검토자 직접 학습 기능 사용법

1. 기존 프로그램에서 기준 PDF와 검토 DXF를 선택합니다.
2. '종합 도면 검토 · 차이 위치 표시'를 실행합니다.
3. 자동으로 발견하지 못한 차이가 있으면 비교창에서 '차이 직접 추가'를 누릅니다.
4. 차이 유형(중심선 / 지름 / 치수·깊이 / 형상 / 공차 / 텍스트),
   차이 이름, 양쪽 도면의 표기/설명, 판정 및 근거를 입력합니다.
5. 목록에서 방금 추가한 항목을 선택하고 'PDF 위치 지정'을 누릅니다.
   메인 화면의 기준 PDF에서 마우스 오른쪽 버튼을 누른 채 드래그하여 위치를 지정합니다.
6. 같은 방법으로 'DXF 위치 지정'을 누른 뒤 검토 DXF 영역도 지정합니다.
7. 비교창의 '학습 사례 저장'을 누릅니다. 두 도면의 위치를 모두 지정해야 저장됩니다.
8. '학습 사례 관리'에서 등록 내역을 확인하거나 잘못된 사례를 삭제할 수 있습니다.

학습 데이터는 reviewer_learning.sqlite3에 저장되며, 정확히 동일한 PDF/DXF 파일 내용(SHA-256)에서
종합 검토를 다시 실행하면 '학습' 항목으로 표시됩니다.
파일을 변경하면 옛 위치를 새 도면에 강제로 적용하지 않습니다.
학습은 사용자가 저장한 검토 사례를 재표시하는 기능이며 AI 모델 가중치를 재학습하는 기능은 아닙니다.
기존 깊이 수정 기능은 사용자가 승인한 기존 지원 예제에 대해서만 적용합니다.
도면 원본을 학습 저장으로 변경하지는 않습니다.
