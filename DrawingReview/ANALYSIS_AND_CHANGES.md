# 형상 분석 수정 내역

## 적용
- 중첩 INSERT/MINSERT의 원과 선을 월드 좌표로 펼쳐 분석합니다. 치수 블록을 부품 형상으로 분해하지 않습니다.
- 순환 참조와 깊이 16 이상의 블록, 클리핑 블록은 건너뜁니다. 비균일 축척으로 타원으로 변환된 원은 원 비교 대상에서 제외됩니다.
- 곡선 bulge가 있는 LWPOLYLINE을 직선 다각형으로 잘못 비교하지 않습니다. 곡선 윤곽 비교 자체는 아직 미지원입니다.
- 일반 치수 분석을 형상 선택과 독립 실행하고, 선택하지 않은 종류는 결과에 섞이지 않도록 했습니다.
- 가상 객체는 정확한 표시 핸들이 없으므로 위치 박스를 추측하지 않습니다.

## 검증
python -m unittest discover -s tests -p 'test_*.py' : 신규 테스트 3개 통과
python tests/test_native_geometry.py : 기존 회귀 검사 통과
GUI/Windows/STEP 실제 실행 및 사용자 실패 도면 정확도는 미검증입니다.

## 남은 한계
- _groups는 서로 다른 원 중심 3개 미만을 제외합니다.
- _match_group은 중심 개수가 다르거나 16개를 초과하면 대응하지 않습니다. 구멍 누락과 큰 패턴에 취약합니다.
- 반복/대칭 형상, 원 중심 이동, 복잡한 곡선/스플라인은 여전히 수동 검토가 필요합니다.
- 균일 축척을 허용하므로 실제 부품 전체 크기 변경과 출력 축척 변경을 구분하지 못합니다. 단위/축척 정책 UI가 필요합니다.
- _closed_outlines는 16개 이하 꼭짓점의 간단한 윤곽만 다룹니다.

## 다음 구현 권장
1. 단위/도면 축척 모드 선택과 미지원 객체/미대응 형상 수 표시.
2. 투상도별 외곽 정합 후 부분 대응으로 구멍 누락/추가를 검출. 반복 패턴은 검토자 연결 사용.
3. 정답 데이터에 양쪽 파일 해시, 객체 ID와 가상 객체의 블록 경로, 영역, 대응 여부, 차이 종류, 검토자와 버전을 기록.
4. 파일/부품 단위로 훈련·검증·시험 분리. 최초에는 같은 형상 대응 모델을 훈련하고 기존 규칙과 함께 후보 생성.
5. 데이터 내보내기, 훈련 명령, 평가 지표(대응 정확도·차이 검출 재현율·오검출률), 모델 버전/되돌리기를 별도 추가.
현재 SQLite 학습 사례 기능은 모델 훈련이 아닙니다. 이번 수정에도 모델 훈련은 포함하지 않았습니다.

## 정리 권장
- 과거 PDF-DXF 안내와 최신 DXF-DXF 안내는 구분하고 깨진 파일명을 정리.
- 예제별 깊이 수정 프리셋은 실습 모드로 분리. 일반 형상 분석에 불필요합니다.
- 3D 뷰어는 선택 설치로 분리. 현재 Setup.cmd는 2D 사용자에게도 gmsh를 강제 설치합니다.
- 기존 검토 사례 저장은 유지하되 모델 훈련과 이름/화면을 구분.
- 의존성 버전 고정과 대표 기준 DXF 예제 추가가 필요합니다.
