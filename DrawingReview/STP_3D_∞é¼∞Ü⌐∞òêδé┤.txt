[STEP/STP/STL 3D 형상 뷰어 안내]

1. 새 PC에서 최초 1회 Setup.cmd 실행 (인터넷 연결 필요)
   - ezdxf: DXF
   - PyMuPDF: PDF
   - Pillow: 3D 음영 렌더링
   - gmsh + OpenCASCADE: STEP/STP CAD 표면 메시 생성
2. 이후 Run.cmd 실행
3. 오른쪽 원하는 3D 창의 [파일 선택] -> STEP/STP/STL 선택
4. 마우스 왼쪽 드래그 회전 / 오른쪽 드래그 이동 / 휠 확대·축소
5. [표준/정밀] 전환: 곡면 메시의 촘촘함 선택 (정밀은 시간이 더 걸릴 수 있음)
6. [초기화] 기본 방향 및 배율 복원

[유의 사항]
- 형상 미리보기는 삼각형 메시 기반이며 CAD 원본의 B-Rep 곡면/공차/치수 검증 도구가 아닙니다.
- STEP/STP 원본 파일은 변경하지 않습니다. 메시 캐시는 LOCALAPPDATA\DrawingReview\mesh_cache 에 저장됩니다.
- 대용량 모델은 75,000개 삼각형을 넘으면 누락된 면을 만들지 않도록 안내 메시지를 표시합니다.
- 메시 생성은 별도 프로세스에서 수행하여 변환 중에도 GUI가 응답하게 합니다.
- 변환 실패 시 Check_3D.cmd를 실행해 Gmsh 설치 및 초기화 상태를 확인하세요.
- Windows 64비트 Python 권장. Windows의 환경에 따라 Visual C++ 런타임 DLL이 필요할 수 있습니다.
- 모든 STEP/STP 파일을 지원하는 것은 아니며 손상된 모델이나 특수한 변환 데이터는 열리지 않을 수 있습니다.


[CATIA STEP/STP 정밀 표시 안내]
1. CATIA에서 내보낸 STEP/STP 파일을 해당 행의 3D 파일 선택으로 불러옵니다.
2. 정밀도를 정밀(권장)/표준/고정밀 중 선택합니다. 파일 변경 시 새 메시를 생성합니다.
3. 윤곽선은 항상 표시하며, CAD 면 경계와 실제로 꺾이는 모서리를 중심으로 나타냅니다.
4. 큰 모델에서 메시 생성 또는 화면 처리 제한에 걸리면 표준 정밀도로 변경하세요.
5. 시각화용 삼각형 메시이며 CATIA의 정확한 곡면/B-Rep 치수 측정은 지원하지 않습니다.

[CATIA 원본 색상 / Shading with Edges 표시]
- STEP/STP의 면별 색상 정보가 포함되어 있으면 원본 RGB 색상을 가져옵니다.
- 원본 색상은 조명에 따른 밝기만 조절합니다. 별도 연보라색으로 덮어쓰지 않습니다.
- 색상 없는 STEP/STP 면과 STL은 회청색 기본색으로 표시합니다.
- 홀/형상 윤곽선은 검정에 가까운 색상으로 표현합니다.
- CATIA에서 색상을 포함하지 않고 STEP으로 저장하면 뷰어가 원본 색을 복원할 수 없습니다.
  CATIA에서 STEP 내보내기 설정의 색상/AP214 또는 AP242 저장 옵션을 확인하세요.
- 큰 파일에서는 '표준'으로 먼저 시험하고 필요시 '정밀/고정밀'으로 높이세요.
- 기존 메시 캐시와 구분하여 색상 포함 캐시를 새로 생성합니다.
- 본 3D 형상 뷰어는 삼각형 미리보기이며 CATIA의 B-Rep 편집/측정 기능은 포함하지 않습니다.

[2026-11 형상 상세 음영 개선]
- CAD 면의 고유 식별자를 보존해 챔퍼/홀/필렛 경계선이 보이도록 개선했습니다.
- 면 내부 삼각형을 일일이 선으로 그리지 않습니다.
- 주광/보조광으로 홀 벽면, 카운터보어와 챔퍼의 입체감을 강화했습니다.
- 화면 안티앨리어싱으로 작은 원호가 톱니처럼 보이는 현상을 줄였습니다.
- STEP에 기록된 RGB 색상을 우선 사용하고, 색상 없는 면은 기본 회청색을 적용합니다.
- 본 기능은 미리보기용 삼각형 렌더링이며 CAD 원본 B-Rep 면 편집을 지원하지 않습니다.
