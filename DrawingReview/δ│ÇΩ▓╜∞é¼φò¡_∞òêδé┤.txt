도면 검토 통합 실습 — 3D 형상 및 문서관리 개선

1. 오른쪽 기준 PDF / 검토 DXF / 검토용 PDF 각 행 오른쪽에 독립적인 3D 형상 뷰어를 배치했습니다.
   - 3D 뷰어의 [파일 선택]에서 STEP(.step/.stp), STL(.stl)을 지정합니다.
   - 왼쪽 드래그: 회전, 오른쪽 드래그: 이동, 마우스 휠: 확대/축소, [초기화]: 기본 시점.
   - STEP/STP 변환은 별도 gmsh 패키지가 필요합니다. Setup.cmd에서 설치를 시도합니다.
   - STL은 추가 변환 패키지 없이 사용 가능합니다.
   - 매우 복잡한 모델은 화면을 빠르게 움직이기 위해 일부 면을 추출해 표시합니다.
   - 각각의 뷰어는 독립적으로 파일을 불러오며 STEP/STP 원본을 수정하지 않습니다.
2. 상단 관리자 [추가] / [삭제]를 지원합니다. 삭제 시 확인 창이 표시됩니다.
   - 마지막 관리자 한 명은 삭제할 수 없습니다.
   - 관리자 목록: %LOCALAPPDATA%\DrawingReview\managers.json
3. 검토 날짜는 프로그램 시작 시 오늘 날짜로 표시하며 YYYY-MM-DD 형식으로 직접 수정 가능합니다.
   - 날짜 입력은 [정보 저장] 또는 [문서 정보 입력/저장] 저장 시 검사합니다.
4. 문서 정보는 도면 번호, 품명, REV, 비고, 검토 날짜, 관리자, 회사명, 도면 경로를 예제 번호별 저장합니다.
   - 저장 위치: %LOCALAPPDATA%\DrawingReview\document_info.json
   - [문서 정보 입력/저장]에서 입력 후 저장할 수 있습니다.
   - 다른 예제를 선택하면 해당 예제에 저장된 정보를 읽고, 저장된 정보가 없는 경우 당일 날짜가 표시됩니다.
5. 좌측 작업 창과 우측 도면 창의 독립 세로 스크롤을 유지했습니다.

주의: STEP/STP는 CAD 커널 기반 메시 변환이 필요합니다. gmsh 설치에 실패할 경우
STL 파일로 변환한 뒤 열거나 Python 환경의 gmsh 설치 문제를 해결해 주세요.
